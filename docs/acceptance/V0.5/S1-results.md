## 逐轮结果与负控

- Builder run-001：Unknown通过；第一个客户端 Keep-Alive 响应后关闭，测试误假定支持下游复用而 FAIL。7个请求，正常清理并保留证据。[返工001](../../leader/reworks/V0.5/S1-rework-001.md)确认 Gateway 仅支持上游池复用，下游仍每连接单请求；修订测试而不增加产品功能。
- Builder run-002：6/6、30请求/29后端，15.408s。随后完善每个Gateway两模型交叉覆盖及逐项清理。
- Builder最终 run-003：6/6、30请求/29后端，15.542s。既有Release CTest21/21、43.10s，四组检测器通过。
- Reviewer独立 run-001：6/6、30请求/29后端，15.543s。独立Release CTest21/21、41.30s；自写审计核对ID分母、实际连接归属、健康转换、流截断与6个子进程回收。
- 独立早期启动失败负控：错误程序非零退出，运行器写FAIL与进程回收证据；重复输出目录拒绝且原文件hash不变。检测器拒绝错误状态、正文/模型、丢失或重复收件、不完整流，以及将超时或完整成功当故障截断。

没有跨轮拼接；run-001失败原因不被后续PASS覆盖。新联调/检测器单独执行，不包含在既有21项CTest计数中。

## 功能观察

| 场景 | 实测结果 | 可得结论 |
| --- | --- | --- |
| Unknown与无健康后端 | 新TCP关闭、不建立后端session | ready不等于Healthy，无fallback |
| 轮询与模型路由 | 六连接覆盖两个Gateway×两个模型；正文ID/模型一致 | L4按连接分配，L7按模型路由 |
| 下游关闭与半关闭 | 正常响应声明关闭；完整请求SHUT_WR后响应完整 | 不支持下游Keep-Alive；半关闭不丢响应 |
| 两实例并发与准入 | 两条门闩流同时到共享后端；第三请求503 queue_full且无后端收件 | 限额为每Gateway独立，不是集群全局配额 |
| 流式与取消 | 后端放行前首段可见；RST后两Gateway均能再处理请求 | 组合链路保留增量流式和取消后可用性 |
| 单Gateway故障 | 承载流HTTP framing不完整，幸存流完整完成；无重复ID | 已有流失败，不自动重放或无缝迁移 |
| 摘除与恢复 | Unhealthy后四新连接仅到幸存者；同端口恢复后两实例均被选 | 已观察到TCP健康过滤和恢复；不承诺摘除前零失败 |
| 全部失效 | 两实例均Unhealthy时拒绝，L4继续运行；重启后恢复 | 无健康后端不导致L4退出 |
| 应用健康边界 | 两Gateway转发模型HTTP503，L4仍Healthy，另一模型成功 | TCP握手无法证明推理服务可用 |

每次完整矩阵30个应用请求，29个唯一后端收件，另有两次不发送有效应用请求的TCP拒绝探测。请求集合固定，不删除拒绝/失败或仅统计成功。流故障以HTTP framing错误判定，socket超时不能冒充预期截断。

## 资源、证据和边界

Builder最终6个自有子进程全部wait回收：3次明确SIGKILL故障注入exit=-9，存活2个Gateway与L4正常exit=0；无清理强杀。结束前FD采样为L4 7→9、Gateway0 7→7、Gateway1 7→8，满足预设+2容差以包含探测瞬态；不据此宣称严格峰值或长期无泄漏。

原始证据位于 `build-local/builder/v0.5-s1/evidence/run-001/002/003` 和 `build-local/reviewer/v0.5-s1/evidence/`；这些运行产物不入Git。仓库保留工具、配置、报告与摘要，可从源码复现。Reviewer构建前后实际源身份一致；Builder在构建后及测试后快照一致。

最终Builder二进制SHA256：Gateway `a4e729016ffaa3b23f785eacefba5a4177a197b901b24cda1291f81d378c0ed1`；L4LB `dc4c217780a3bc189fc65b50ac83345cb2dee240b77269e30138c1dc2403b77e`。每角色运行identity.json另保留自身二进制与工具身份。

本机模拟功能验证不是真实模型兼容重验、GPU收益、吞吐容量、生产高可用或横向扩展证明。L4默认1秒完成后间隔、1秒探测超时、3失败/2成功阈值不构成严格固定秒数切换承诺；同步日志和OS调度也有影响。没有全局配额、自动重试、客户端源地址保留或XDP TCP。V0.5/S2的额外成本及长连接分布边界尚未开展。
