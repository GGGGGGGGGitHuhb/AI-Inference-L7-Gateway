## 取消、资源与限制

R3 两次都先验证首 content 与活跃 request 状态再 RST；L1 本地零账分别 0.107475/0.104530s，≤5s；L2 均记录取消前上游 socket inode，排空后 inode 消失。L3 两次后端 slot 均观察到 idle 且恢复请求成功，只说明本次 CPU 服务观察，不宣称全部计算或 GPU 工作已停止。

真实 global inflight 峰 2、每实例峰 1、队列 count 峰 4/bytes 峰 5312。预热排空 B=4378624bytes；所有排空点 RSS≤4542464bytes，低于 B+32MiB，FD 均回启动基线 7（常驻 listener/signalfd 等）。模拟 M1–M4 baseline RSS=4096000bytes，排空最高4501504bytes，FD均7。每个排空点的 sessions/reserved/stream capacity/pending/paused/upstreams/leased/idle/pool total/retired/inflight/queue count/bytes/timers 全零；M5 以最终零账+退出回收核验，进程退出后没有伪造 live FD。

账本事件及至少100ms快照、1s RSS/FD原始采样保留。真实采样峰：Gateway RSS4542464bytes/FD15；后端分别621416448/621056000bytes，均远小于2GiB。模拟采样很短可能错过活动峰，不能把采样最大值当瞬时上界；host事件累计观察及既有确定性 Admission 测试共同验证限额。allocator 缓存与内核 socket buffer 不等同逻辑预约。
