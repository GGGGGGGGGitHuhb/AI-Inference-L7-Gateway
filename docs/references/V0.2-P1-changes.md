# V0.2/P1 变更与测量来源

2026-10-19。依据[Approved设计](../leader/designs/V0.2/P1-design.md)，只增加 tests/performance 工具、CMake快速入口和P1文档；产品src、第三方、旧测试工具、旧输入、历史角色报告和来源清单保持。起点555b65d66a52d95791dba5445178e57a69b81d2c，分支codex/v0.2-performance-baseline。

| 文件 | 责任与来源 |
| --- | --- |
| tests/performance/Client.py | 新增观测时钟/独立attempt结果；只读继承S3 WireResponse严格解帧，在其finish等待EOF之前独立记HTTP终态；新的确定JSON/SSE fixture |
| tests/performance/Backend.py | 新增每cell独立Python HTTP后端；有界内存请求/发送间隔记录、预热计数快照；没有热路径磁盘日志 |
| tests/performance/Measure.py | 新增有限线程/双发压进程屏障、闭环与C波次、被动/proc采样、唯一cell落盘、协同停止及子结果交接 |
| tests/performance/RunBaseline.py | 固定schedule、实验配置、独立服务生命周期、只读固定资产/许可复核；复用S3 Support的Backend、Host、OwnedProcess、free_port/save/sha，不使用旧exchange或退休发压门 |
| tests/performance/Summarize.py | 成功/失败分离的nearest-rank、每cell与三重复观察范围、资源和控制阈值汇总 |
| tests/performance/DetectorTests.py | HTTP完成/EOF/内容事件、异常分类、晚到结果、实际SIGTERM单/双发压负控；仅测试使用started_audit记录，与正式热路径分离 |
| CMakeLists.txt | 仅追加PerformanceDetectors快速CTest入口；不把模型或完整矩阵加入默认回归 |
| tests/performance/README.md | 可复现命令、原始证据schema与统计边界 |

固定短prompt只读使用tests/integration/Inputs.json。llama.cpp b7481和Qwen GGUF/revision/Apache2许可沿Approved固定资产；每次完整run记录assets.json、license.json、server和库SHA、实际进程CLI。不存在新下载、安装或产品依赖。

初次run-001与最终run-002身份分开。run-001结束并完成源/样本审计后保存initial-source；交付前强化协同取消、子进程完整收集、发送绝对期限、DONE终态校验，以及批次end精确为最后worker t_closed，再执行唯一一次完整重跑。两个run和全部初始负控失败都保留；不选性能最好的一次。

最终逐文件SHA、差异与历史保护结果由build-local/builder/v0.2-p1/evidence的manifest和final-audit记录；用户结果在[结果文档](../performance/V0.2/P1-results.md)。本文不改旧来源manifest，也不把历史S3 soak计数转换成性能数据。
