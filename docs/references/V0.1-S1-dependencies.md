# V0.1/S1 第三方依赖

| 依赖 | 固定版本 | 内容 | 许可 |
| --- | --- | --- | --- |
| nodejs/llhttp | release/v9.4.3 | include/llhttp.h，src/api.c/http.c/llhttp.c | LICENSE-MIT |
| nlohmann/json | v3.12.0 | single_include/nlohmann/json.hpp | LICENSE.MIT |

[manifest.json](../../third_party/manifest.json) 保存每个直接下载文件的固定标签官方 URL 和实际 SHA-256，包括许可证文件。下载物就是保存的文件，没有二次生成或解包。来源为 GitHub 官方仓库的 raw.githubusercontent.com 固定标签；没有使用系统同名库或浮动分支。

正常 configure/build/test 使用本地快照，不联网，不需要 Node/TypeScript 或 Python 包安装。CMake 只编译 llhttp 的 C 源码，JSON 仅由 TextRequest.cpp 私有包含。第三方文件不改名、不格式化、不修改源码。Manifest 测试逐文件重新计算 SHA-256。

工具要求：Linux、支持 C++20 的编译器、CMake >=3.24、Ninja、Python 3 标准库；自有代码排版用 clang-format 18。实际版本和命令见 Builder 报告。项目自身未选择许可证，不能将第三方 MIT 扩张为整个项目的授权声明。
