# V0.3/S2 自有实现来源与边界

起点 b704df268e2865bda146ba4c816dd105e6c8302c。新增准入与排队为本仓库自有实现，不引入依赖、不迁入Server/L4LB实现。旧Approved/角色报告/第三方/旧测试断言/P1工具数据保持。

- `src/admission/AdmissionController.*`：稳定ID FIFO、count/逻辑byte强异常记账、模型游标与dirty；不拥有请求正文、Session或Socket。
- `src/app/GatewayConfig.*`：显式opt-in、严格整型与范围、模型模式约束及直接构造验证。
- `src/routing/ModelRouter.*`：原唯一inflight上添加全局求和、健康与容量类型区分、受限RR/LI；失败选择不改变游标/Trial。
- `src/gateway/ProxySession.*`：Waiting、原单一请求所有权、queue/total期限、入出队恰一次、释放仅dirty通知；无重试。保留三个私有单调时刻与结果供friend测试host观察，无产品日志/管理API。
- `src/gateway/GatewayRuntime.*`：稳定ID查表、每轮每模型一个队头/每次32预算、单合并任务、弱有效期token保护、停止先拒绝等待者。Runtime是唯一任务生产者；意外拒绝任务为致命调度错误而非静默丢通知。
- `tests/AdmissionTests.cpp`：自有配置/Router/队列/Session/Runtime门控；FakeIo与socketpair思路来自既有RoutingLifecycle设施，独立适配，不修改旧断言。仅测试可控operator new注入deque分配失败。
- `tests/admission/RuntimeHost.cpp`：仅测试friend装配，在事件清理前后读实际Session/Router/队列，原子写临时观察文件；记录Session ID、模型/流标志、accepted/enqueued/dispatched/upstreamComplete/finished。采样发生于单线程事件边界，瞬时限额另由确定性断言验证；不声称RSS或无观察开销。
- `tests/admission/RunAdmission.py`：Python标准库门控后端、RST/SHUT_WR/超时/停止负控；`--mixed`独立运行固定24条，统一门闩及交替发送，实际FIFO按host时间验证，所有尝试保留。不是性能比较/长期饥饿证明。
- CMake新增Admission、AdmissionE2E和测试host；新配置示例与README说明opt-in、错误及预算边界。

Builder报告给出最终源/三套binary身份、所有失败与成功日志、逐AC证据及混合原始样本；独立验收由Reviewer决定。
