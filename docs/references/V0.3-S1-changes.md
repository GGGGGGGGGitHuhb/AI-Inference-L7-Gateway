# V0.3/S1 自有实现来源与边界

起点 e231fda25879060fcd730f562982f06448f2ba11。所有新增代码为本仓库自有实现，未引入依赖或迁入Server/L4LB代码；third_party、旧来源manifest、P1工具/数据及历史报告不改。

- `src/routing/ModelRouter.*`：静态目录、RR/LI、请求租约、健康epoch及冷却时间比较；无socket/后台timer。
- `src/app/GatewayConfig.*`：显式多层白名单、数量/标识/端点/资源乘积校验，保留legacy模式。
- `src/gateway/GatewayRuntime.*`：每(model,id)池所有权、聚合和实例快照、清理/停机顺序。
- `src/gateway/ProxySession.*`：准确终结健康观察与独立连接归池epoch检查；错误体和既有deadline契约保持。
- `src/upstream/ConnectionPool.*`：抽出可恢复的 `clearIdle`，不永久停止摘除实例池。
- `src/http/HttpParser.*`：ParseFailure为通用协议/资源保护/内部错误分类。原响应错误统一502，不能据其区分健康失败与本地保护；新增类型不改变原errorStatus/errorCode或HTTP层依赖方向。fragment/informational限制原502外部映射保持，只标本地限制类别。
- `tests/RoutingTests.cpp`、`RoutingLifecycle.cpp`：新确定性状态和Session装配测试。FakeIo基础来自仓库既有RuntimeTests测试设施，独立适配新路由构造，不修改旧断言。
- `tests/RoutingE2E_test.py`：标准库受控服务/正式网关进程，最终finally回收，所有负配置必须实际失败退出。
- CMake注册Routing与RoutingE2E；config/routing-example.json和README新增中文使用说明。

当前源与三预设二进制SHA清单由Builder报告指向独立evidence目录；每个失败自检日志保留编号，不覆盖为成功。最终验收由独立Reviewer决定。
