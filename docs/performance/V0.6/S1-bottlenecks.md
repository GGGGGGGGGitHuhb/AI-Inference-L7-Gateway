# V0.6/S1 瓶颈证据与优化交接

状态：两角色各72项正式矩阵及关键控制已完成，工具/有界诊断交付独立PASS；产品极限归因与S2入口BLOCKED。详见[完整结果](S1-results.md)与[Reviewer001](../../reviewer/reports/V0.6/S1-report-001.md)。原始引用及指纹见[S1清单](S1-manifest.json)，执行依据见[S1设计](../../leader/designs/V0.6/S1-design.md)。

## 1. 流式路径：流缓冲配置先于32连接额度生效

Builder探索S/G在240req/s通过、480req/s达标81.667%、960req/s达标45.02%。源码默认流缓冲总额4MiB，每条流预约256KiB，因此至多16份流缓冲预约；连接/准入额度32不代表同时允许32条流。证据为GatewayConfig与BufferBudget常量、`E1-S-G-480`/`E1-S-G-960`的拒绝结果，以及`E2-S-G-480-stream8`。

单变量控制只把流缓冲总额4MiB改为8MiB，480req/s达标比例升至100%；保持4MiB而改为双发压的`E2-S-G-480-w2`仍为81.667%。这支持该点主要受流缓冲额度限制，而非发压进程数。Reviewer同一控制为81.25%→100%，支持配置限制的可复现性；不是产品代码性能提升。正式基线保持聚合4MiB，双Gateway各2MiB，避免实例增加时隐式翻倍资源。

可行动方向是检查与配套调整流缓冲、准入、连接和内存预算。风险是更高并发消耗更多内存，并可能把瓶颈推向后端或发压器。该证据支持配置调优，尚不支持修改执行架构或认定CPU处理能力上限。

## 2. JSON高档：发压工具敏感与重复波动

单发压A/G3840探索的发压进程约0.948core，已超过0.85忙核标记。双发压保持总速率和128总槽数后，HTTP P95由约3.577ms变为3.127ms，变化超过预注册10%门槛；P99也明显变化。单发压高档不能独立用于归因网关。

匹配校准中改用双发压后各发压进程约0.64–0.67core；匹配配置的960/1920/3840均满足探索筛选，正式候选取最高三个有效档。3840双发压两次达标比例约99.047%与99.979%，说明临界点存在重复波动，不能选取最佳值。quota64控制约99.354%，不足以证明增加连接/准入额度有稳定收益。

替代解释包括主机调度、连接建立与关闭、后端/客户端工具开销及采样影响。正式重复和连接复用/采样控制已保留这些差异；没有CPU饱和、调用栈或单变量证据时，不把分配器、epoll、Nagle或线程模型命名为已确认产品瓶颈。

L路径A3840在Builder三次为99.159%/85.246%/85.652%，Reviewer为86.085%/83.163%/83.781%，高档退化已独立复现；L1920双方全部三次通过。G/M3840双方全部三次通过，但不能据此把L的瓶颈指定为Gateway本体。Builder部分后端样本超过0.85core；Reviewer L高档后端约0.842–0.850、发压约0.825–0.844core，不应直接标为严格超过0.85。未隔离同机资源、后端及调度因素。

末两配套quota32/64控制采用双方相反顺序：Builder达标98.776%/98.984%，Reviewer cap64/32为99.010%/98.875%，后者cap64尾延迟更差。短窗口单对且跨角色不一致，不能认定增加额度稳定解决高档失败；也不能归因某个CPU函数或日志阻塞。

## 3. 上游连接与采样开销诊断

Builder的A/G960双发压控制中，reuse off/on均达标100%，6720个后端请求对应accept由6720降至23，空探针为0；HTTP P95约2.701→2.190ms，P99约7.144→2.571ms。这是既有上游复用能力的单次配置控制，不是新增代码收益。主曲线仍关闭复用；该复用控制未单独做独立重复，保留为候选，不外推为所有负载的收益幅度。

100ms/500ms资源采样控制均达标100%，P95约2.664/2.625ms，P99约3.389/3.512ms；采样读取累计约123.77/27.02ms。较低采样开销未在该单点改变达标状态，但更稀疏采样会降低峰值可见性，因此主曲线保持100ms。

Builder三次、Reviewer一次正式收口首停分别涉及L4多词结束理由及窗口外进程资源读取。全部按返工001–004保留并复核，最终工具只在窗口外经实际退出确认后跳过退出样本；窗口内或仍活进程异常仍失败。它们不作为产品吞吐瓶颈证据，也未抹去低达标样本。具体内核或CPython退出原因未被证明，不能命名为产品故障。
